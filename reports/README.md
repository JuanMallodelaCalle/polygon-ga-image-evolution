# Reports

This folder contains the original academic report associated with the project:

- `polygon_ga_image_evolution_paper.pdf`

The report was prepared for the Bio-inspired Learning course of the Master's Degree in Signal Theory and Communications at Universidad Politécnica de Madrid.

The PDF contains visual examples from the original coursework, including external target images and evolved polygon-based approximations. These images are not covered by the repository license unless explicitly stated. See [`../docs/image_sources.md`](../docs/image_sources.md) for source and licensing notes.
