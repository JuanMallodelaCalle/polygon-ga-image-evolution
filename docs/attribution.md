# Attribution

This repository is based on the academic group project **Evolutionary Generation of Targeted Images Using a Polygon-Based Genetic Algorithm**, developed for the Bio-inspired Learning course of the Master's Degree in Signal Theory and Communications at Universidad Politécnica de Madrid.

Original contributors:

- Juan Mallo de la Calle
- Sergio Melones Peña
- Jesús Rincón Laguarta

This public repository is a curated portfolio version maintained by Juan Mallo de la Calle. The goal of this version is to make the project easier to understand, navigate and reuse as an educational example of evolutionary computation for image approximation.

The included academic report preserves the original project context and authorship.
