# Image Sources and Licensing Notes

This project evolves target images into polygon-based approximations using a Genetic Algorithm. Some visual examples included in the academic report are based on external images. The repository license applies to the code, documentation and self-generated project materials, but not automatically to third-party target images.

The original academic experiments used three targets:

1. A grayscale Albert Einstein portrait.
2. A geometric tiger illustration.
3. Vermeer’s *Girl with a Pearl Earring*.

The repository does not redistribute standalone copies of these target images or generated outputs outside the academic report. This avoids ambiguity around third-party image licensing while still preserving the original coursework report for documentation and portfolio context.

| Image / Target | Use in Project | Source / Status | Notes |
|---|---|---|---|
| Girl with a Pearl Earring | Target image and evolved approximation | Public-domain artwork; Wikimedia Commons provides public-domain reproductions of the Vermeer painting | Suitable for public educational examples if sourced from a public-domain reproduction. |
| Albert Einstein portrait | Target image and evolved approximation | Wikimedia Commons hosts public-domain versions of the 1951 Arthur Sasse photograph in the United States | Reuse may depend on jurisdiction; source should be cited if reused directly. |
| Geometric tiger illustration | Target image and evolved approximation | Original source not fully verified | Included only as part of the original academic report. Not recommended for standalone redistribution unless the original license is identified. |

For reproducibility, users should provide their own local target images in `data/targets/` and update the notebook path accordingly. Users should verify the licensing status of any target image before reusing it outside this educational portfolio repository.
