# Data Folder

This folder is reserved for local target images used by the notebook.

Target images are not included as standalone files because users may want to experiment with their own images and because external images may have different licensing conditions.

Recommended local structure:

```text
data/
└── targets/
    └── target.png
```

The academic report included in `reports/` contains the original coursework examples. Those visual examples should be treated according to their original source licenses or public-domain status, as documented in `docs/image_sources.md`.
